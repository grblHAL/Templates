## Constants

Adds some named parameter constants.

| Parameter | Description                                   |
| ----------| --------------------------------------------- |
| _pi       | Pi (&pi;) - `3.1415...`                       |
| _raddeg   | Radians per degree - `0.0174...`              |
| _m2i      | Metric to imperial conversion factor - `25.4` |
